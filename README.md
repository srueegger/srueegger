Web Developer based in Basel, Switzerland

Blog: [rueegger.me](https://rueegger.me)

## About me / Über mich

**English**  
I am a full-stack web developer focused on modern, scalable and user-friendly
digital experiences. I work primarily with PHP, JavaScript, Node.js, Vue, React,
HTML and CSS/SCSS, and I build native Linux applications in Vala and Rust. I enjoy
exploring new tools and frameworks. Outside of work you will usually find me
swimming in the Rhine, tinkering with Linux systems or building LEGO Technic models.

**Deutsch**  
Ich bin Full-Stack Web-Entwickler mit Fokus auf moderne, skalierbare und
benutzerfreundliche digitale Erlebnisse. Ich arbeite hauptsachlich mit PHP,
JavaScript, Node.js, Vue, React, HTML und CSS/SCSS und entwickle native
Linux-Anwendungen in Vala und Rust. Neue Technologien probiere ich regelmassig aus.
Wenn ich nicht programmiere, schwimme ich im Rhein, bastle an Linux-Systemen
oder baue LEGO-Technic-Modelle.
